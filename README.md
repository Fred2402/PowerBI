# Dashboard Budget 50/30/20 — Power BI

## Description
Pipeline ETL complet et dashboard interactif pour analyser 
et catégoriser des transactions bancaires personnelles 
selon la règle budgétaire 50/30/20.

## Données
- 1 200+ transactions multi-sources
- Sources : Boursorama, Crédit Mutuel, Trade Republic

## Pipeline
- Collecte et centralisation des données
- Nettoyage et normalisation via Power Query
- Catégorisation automatique par mots-clés JSON
- Modélisation en schéma étoile

## Fonctionnalités
- Dashboard 4 pages interactif
- Ratios Besoins / Envies / Épargne
- Suivi des investissements
- KPIs financiers dynamiques (DAX)

## Technologies
Power BI · Power Query · DAX · JSON · ETL
